# Diagrams of the guides

The diagrams of `docs/*.md` in the design of the Chair of Railway Operations (TU Dresden): `<guide>-NN.mmd` is
the Mermaid source, `<guide>-NN-light.svg` and `-dark.svg` the pictures (Noto Sans embedded). A guide shows the
one that matches the reader's light or dark setting. To change one, edit the `.mmd` and render again (see
[CONTRIBUTING.md](../../CONTRIBUTING.md#keeping-the-architecture-page-true)).
