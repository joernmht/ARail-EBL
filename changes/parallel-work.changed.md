- **Working in parallel without conflicts** ([Contributing](CONTRIBUTING.md#working-in-parallel)): pull requests add a **changelog fragment** (`changes/<topic>.<kind>.md`) instead of editing `CHANGELOG.md`; `node tools/changelog.mjs` merges them into "Unreleased" at a release, and `tests/js/changelog.test.js` checks them. The built-in object types and simulations are registered in `web/arail/objects/index.js` and `web/arail/sims/index.js`, one per line (`registerObjects`, `registerSimulations`, `OBJECT_TYPES`, `SIMULATION_TYPES`); `web/arail/index.js` re-exports them, its API is unchanged. The framework's German texts are kept in one file per area (`web/arail/i18n/de/*.js`, joined in `de.js`, `DE_PARTS`), the builder's apart from the app's (`web/app/lang/de-builder.js`); the i18n test also finds a text in two area files.
