- **Fit to run: a finding written into the release is a judgment, not a mistake** ([The workshop hall](docs/workshop.md), `web/arail/game/workshop.js`): fleet management that wants a finding repaired at the return to operation no longer keeps the unit in for the night. It sends the release back, and with it the unit, which goes into the hall again with the repair ordered and 20 min to set up for it again; a brake hose changed then means the brake test again, signed again, and a time said to the dispatcher for the unit counts by the new release; whether it still makes a train, the night decides. A finding that may wait costs the fleet manager little in a release (3 points of patience, less than a call at night); one that sends a unit back costs 24, and 0.12 of the night's orders. Leaving a finding in the release where the foreman says it can run now beats the book on 28 nights of 100 and loses on 7; where it can go either way it is a gamble (49 against 34); every finding there, the chafed brake hose too, still does not pay. A unit is now kept in only for a release signed without authorisation.
