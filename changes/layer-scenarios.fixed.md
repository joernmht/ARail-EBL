- **A scenario that a module replaces is no longer lost** (`decomposeLayout`, `web/arail/core/layers.js`): a layer's scenario with the id of one of the base replaces it while the layer is on, but writing the layout back (switching a module off in the app, saving) filed only the layer's version and dropped the base's. Now the replaced scenario goes back to where it came from, also when two layers replace the same one, and switching the module off brings it back.
