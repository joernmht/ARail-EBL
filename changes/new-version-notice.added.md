- **A new version is offered**: each deploy stamps the commit it publishes (`version.json`, and the meta `arail-version` of the app and the game page). An open page asks for it when it starts, every ten minutes and when it is shown again. A page older than the site (a tab left open, or files the browser kept in its cache) says *A new version of ARail is available*: **Reload** saves the layout's edits, fetches the page's files anew past the cache and loads the new version; **Later** hides the notice until the next check.
