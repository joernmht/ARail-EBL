- **One error in the marker worker no longer slows the camera for the rest of the visit** (`web/app/detection.js`, `web/live/detect-worker.js`): any error the worker answered, also for a single frame or for setting it up anew after a network blip, shut it down, and the app searched every frame of the camera and of clips on the main thread from then on. Now a frame the worker cannot search is skipped, and setting it up that fails is asked once more; only when that fails too, or five frames in a row fail, does the main thread take over.
- **An example no longer turns modules back on that were switched off by hand** (`web/app/app.js`, `switchOnLayers` in `web/arail/core/layers.js`): Examples → Hump yard switched on a fixed list of modules, the Striezelmarkt among them, and kept it as the choice for Bf Neustadt, so a market switched off before came back and stayed on. An example now switches on the module it needs with the modules chosen before (`switchOn` of an example), as Examples → Sandbox does; so do Infrastructure, Journeys and the other module examples when Bf Neustadt is not open yet, which switched the town's modules off before, and the game's *Bf Neustadt and its terminal* (`web/game/main.js`).
- **The Striezelmarkt also comes for those whose last choice was Operations** (`layersKnown`, `web/arail/core/layers.js`): an exclusive module chosen alone keeps the other modules off, and the app still noted the market as known, so a returning user whose last choice was *Operations* or *Breakdown* never got the market the layout gained. Now the modules it kept out stay new and come when the exclusive module is left.
- **Objects of plugins without `shown()` are drawn again** (`World.draw`, `web/arail/core/world.js`): an object of a plugin that does not extend `LayoutObject` could be pointed at, but drawing the world stopped with an error on it; it now counts as shown, as when pointing at things.
