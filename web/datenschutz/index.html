Datenschutzerklärung

Stand: 11. Oktober 2026

In short

  • The app runs entirely in your browser. Camera images, photos, videos and your layouts are processed on your device and are not sent to us or anyone else.

  • The site is hosted on GitHub Pages. GitHub logs the IP address of every visitor for security purposes.
  • The German text below is authoritative.

3. Die App: Verarbeitung nur in Ihrem Browser

Die App läuft vollständig in Ihrem Browser. Es gibt keinen Server, der Ihre Eingaben empfängt.

  • Kamera, Fotos und Videos. Die Live-Kamera wird erst genutzt, wenn Sie sie einschalten und Ihr Browser Sie um Erlaubnis gefragt hat. Kamerabilder, Fotos und Videos, die Sie aufnehmen oder öffnen, werden nur auf Ihrem Gerät ausgewertet, um die Marker zu erkennen, und nicht übertragen oder gespeichert.
  • Layouts und Einstellungen. Bearbeitete Layouts, die gewählten Module, Anzeige- und Simulationseinstellungen, eine Kamerakalibrierung, die Adresse der Leittechnik-Anbindung und die Einstellungen der Markerbögen werden im lokalen Speicher Ihres Browsers (localStorage) abgelegt, damit sie beim nächsten Besuch noch da sind. Sie verlassen Ihr Gerät nicht. Sie können sie jederzeit löschen, indem Sie die Websitedaten dieser Seite in Ihrem Browser löschen. Das Speichern ist für diese von Ihnen gewünschten Funktionen unbedingt erforderlich (§ 25 Abs. 2 Nr. 2 TDDDG).
  • Exportierte Dateien (Layouts, Aufnahmen des Bildes, Ergebnisse, Markerbögen) erzeugt Ihr Browser und speichert sie auf Ihrem Gerät.
  • Anbindung an eine Leittechnik. Wenn Sie unter Settings → Control system eine Verbindung herstellen, verbindet sich Ihr Browser mit der Adresse, die Sie dort angeben (voreingestellt ist Ihr eigener Rechner, localhost). Wir erhalten dabei keine Daten.
  • Inhalte von anderen Adressen. Öffnen Sie selbst ein Layout oder ein Bild von einer anderen Website (etwa über die Parameter ?layout= oder ?image=), lädt Ihr Browser es von dort; dafür gilt der Datenschutz jenes Anbieters.

4. Keine Cookies, keine Analyse, keine Inhalte Dritter

Diese Website setzt keine Cookies und verwendet keine Analyse- oder Tracking-Werkzeuge. Schriften, Skripte, Bilder und Videos werden von dieser Website selbst geladen, nicht von Servern Dritter (etwa Google Fonts oder Content-Delivery-Networks).

5. Links zu GitHub

Links zum Quelltext, zur Dokumentation und zu den Fehlermeldungen führen zu github.com. Erst wenn Sie einem solchen Link folgen, verarbeitet GitHub Ihre Daten nach seiner eigenen Datenschutzerklärung. Was Sie dort in Issues schreiben, ist öffentlich.

Die E-Mail wird über die Server der TU Dresden empfangen. Wir löschen sie, wenn sie erledigt ist und keine Aufbewahrungspflichten entgegenstehen.
