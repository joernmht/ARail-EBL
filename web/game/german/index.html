How it is played

    Why "German mode": a network that carries more trains every year on the same tracks runs well for a long time, and then, quite suddenly, not at all. Capacity is not used up evenly: the last trains cost the most.

    German mode of the ARail game: the signal box and the container terminal under a load that only rises (the game design).
