Bring it to your lab

Stickers, a phone, a browser

Digital twins are boring. We built a sister: an image of the layout that is laid over it, and technically independent of it. Any scale: H0, TT, N.

  1. 1StickArUco or AprilTag markers, 30 mm, one every 30–40 cm. Print them from the marker sheets.
  2. 2FilmOne slow video of the table. arail-survey measures every marker and writes the layout and an orthophoto.
  3. 3BuildPlatforms, streets, houses, a terminal: in the flyover (F), on a grid, also beyond the real table.
  4. 4Connectarail-bridge brings the positions of the real trains from your control system, or from the built-in simulator.

For developers: plugins

No build step, no framework. A plugin is an ES module that registers object types, simulations or disruption types; layouts load it by URL. Guide to plugins · Layout file format · Control-system interface

// plugins/windmill.js: a new object type
export default function (arail) {
  class Windmill extends arail.LayoutObject {
    static type = "windmill";
    static label = "Windmill";
    static params = [{ key: "height_m", label: "Height", type: "number", unit: "m", default: 18 }];
    computeGeometry() {
      const c = arail.resolvePoint(this.world.map, this.spec.position);
      return c && { center: c };
    }
    draw(view) {
      const [x, y] = this.geometry.center;
      const h = view.m(this.spec.height_m);   // metres → model mm
      view.prism(arail.rectFootprint([x, y], view.m(5), view.m(5)), 0, h,
                 { side: "#e8e1d0", top: "#8a5a3c" });
    }
  }
  arail.registry.registerObject(Windmill);
}

From a sister to a hybrid lab

The first step is done. Next, the sister learns where the real trains are; later, she runs the layout herself.

Stage 1Arrived

The digital sister

An image of the layout that can be laid over it, on any phone, live or projected. Technically independent of the layout: she simulates the lab next to it.

Stage 2Next

The layout writes into the model

Live positions from the lab's control system: physical trains in a virtual world. When a real train stops at a platform, the virtual passengers board it. The bridge runs with a simulator; the adapter for the EBL is next.

Stage 3Later

The sister runs operations

The sister takes over operations control and writes into the layout: disruptions hit the real trains too, flexibly and repeatably, for any exercise.
